# Project rules (Spice Bandits port)

- **Documentation rule:** whenever you identify a function (or data structure) and understand what it does, add it to `docs/KNOWN_FUNCTIONS.md` in the same change (address, name/role, notes). Mapped-out findings must never live only in a commit message or a chat. Update the entry if a later finding corrects it.
- Never commit game binaries or assets (IPAs, `work/`, `ref-images/`).
